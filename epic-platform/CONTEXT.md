# Epic Platform

Cinematic AI media generation studio. Users type prompts → Groq-powered helpful chatbot (strong persona for prompt engineering, advice, iteration) collaborates with specialized agents (Writer, Director, Renderer) using LangGraph + fal.ai (images/video/audio) → studio-quality output with character/world memory. Beautiful cyber-neon glassmorphic UI. Next.js 15 (App Router + TypeScript), Tailwind + shadcn/ui + Aceternity + Framer Motion, Supabase (auth/DB/realtime/storage), Inngest + Upstash Redis for jobs, deployed to Railway.
